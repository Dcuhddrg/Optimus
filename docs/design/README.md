# 设计

需要长期保留的业务与架构设计。新的 spec 和任务拆分记在 [GitHub Issues](https://github.com/Dcuhddrg/Optimus/issues)；重要决定写入 [ADR](../adr/README.md)；记录规则见[文档维护约定](../relations/documentation-workflow.md)。

- 本目录：仍作为现行依据或待核实的设计。
- [archive/](archive/)：已交付阶段的设计，保留当时的背景与决定，不代表已验收。
- `plans/`：仍在进行的实施计划，目前没有。plan 交付后删除，历史从 Git 找回。
