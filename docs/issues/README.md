## 使用方式

- 新问题使用 [统一模板](../../.github/ISSUE_TEMPLATE/issue.md)，填写背景、影响、验收条件和下一步；提交入口为 [创建 Issue](https://github.com/Dcuhddrg/Optimus/issues/new)。GitHub 模板选择器以默认分支为准，本次模板需合入默认分支后生效。
- 新工作用 GitHub `#编号` 关联 spec、实施计划和 PR；重要设计结论写回 docs，不重复维护待办清单。
- 需要业务验收的事项验收后再关闭；网络或权限不可用时说明阻塞，不把本地旧记录当最新状态。
- 下列历史锚点保留兼容旧链接，后续状态只查看对应 GitHub Issue。
