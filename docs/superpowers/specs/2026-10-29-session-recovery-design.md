# 会话恢复错误分类修复

- 关联：#27；范围由用户在本次评审后确认，授权修复。
- 状态：用户已确认修复并授权提交 PR、合入 main；交付与验证记录见 #27，实现、测试与用户验收分别记录。

## 行为

请求层保留 HTTP 状态及网络/协议错误类别。登录是公开请求，其 401 只反馈本次登录失败；携带当前凭据的私有请求明确返回 401 时才统一清理会话。携带旧 token 或已取消请求的 401 不得清理当前会话；被取消的会话恢复结果不得覆盖用户信息。

恢复会话遇到 403、网络、5xx 或协议异常时保留凭据，清空未验证的用户信息，提供本地化失败提示和显式重试。恢复中或失败时不渲染受保护页面。重试只重新读取当前用户，不自动重试写操作。明确 401 和主动退出仍清理凭据。

## 边界与选择

沿用现有 Context、路由和请求封装，用恢复错误状态补充现有 token/current/loading。仅修改请求、认证 API、会话 Provider、守卫、相关文案与回归测试；不引入状态库，不改变后端响应，不混入 #18 协议迁移。只保留凭据而不修改守卫会误放行页面；所有错误都注销则会把暂时故障当作认证失败。本批不重构登录和退出同时发起时的全局并发协调，旧退出请求的 finally 与新登录竞争仍是未覆盖边界。
